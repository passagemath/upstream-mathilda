**Algorithm.** `builtin_dirichletcharacter` checks arity, sends an `NDArray` or packed argument to `dc_ndarray`, and threads over `List` arguments itself through `dc_thread`; the head is only `Protected`, not `Listable`. It validates `(k, j)` with `dch_validate_kj`, which emits the `intp` and `invl` messages, and fetches the cached table from `dch_get`. The labelling is the one `src/special_functions/dirichlet.h` documents as reverse-engineered from Mathematica 14, not the Conrey labelling. `k` is factored with primes ascending, and `(Z/kZ)*` splits into cyclic components. An odd `p^a` gives one component, generated by the smallest primitive root mod `p^a`. The modulus 4 gives one component, generated by 3. A power `2^a` with `a ≥ 3` gives two: the sign component `⟨-1⟩`, then `⟨5⟩`. `j - 1` is written in mixed radix over the components, with the first component most significant, and `χ(g_c) = exp(2πi d_c/ord_c)`. A value `χ(n)` is 0 when `gcd(n, k) > 1`. Otherwise `dch_exp` takes a discrete log in each component (`dlog_comp`), using Pohlig–Hellman over the component order with baby-step giant-step in each prime-order subgroup (`dlog_prime`). It sums the exponents in `Z/ord(χ)`, and `dch_root_of_unity_expr` renders the result exactly as a unit times `E^(I Pi r)` with `r ∈ (-1, 1)`.

**Data structures.** A `DchTable` (cached and immutable once published, so threaded `Compile` loops can share it) holds the components and digits, the order, parity and conductor `f`, the primitive inducing character `χ*`, and the Euler-factor primes. For `f ≤ 2^22` (`DCH_TABLE_MAX`) it also holds dense tables over `0..f-1` of exact exponents and machine values, plus the root number. The dense tables are built by walking powers of each generator, with no logs. All modular arithmetic is overflow-safe on `uint64_t` for `k < 2^63` (`dch_mulmod`, `dch_powmod`). An int64 buffer `n` gives an int64 buffer of `0, ±1` for a real character, and a `List` of exact roots of unity otherwise.

**Complexity / limits.** A dense value costs `O(1)`, and a single value for a large modulus costs about `O(Σ e_i √q_i)` per component. A component order whose largest prime factor exceeds 2^44 leaves the call unevaluated. A non-integer `n` emits `DirichletCharacter::int`. The values are exact, so there is no `Compile[]` lowering; the head is on the compile-coverage `EXEMPT` list.

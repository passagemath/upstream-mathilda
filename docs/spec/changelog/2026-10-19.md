# Changelog: week of 2026-10-19 (Mon) – 2026-10-25 (Sun)

## Correctness/performance: the v0.464 limitations closed; Reduce transcendental roots; InputForm round-trip ; v0.465

- **Reduce over the reals with transcendental breakpoints.** `Reduce` now solves univariate exp-trig-polynomial inequalities and equations whose roots `Solve` cannot find. It isolates the real roots with certified arb interval arithmetic on a provably bounded region and returns them as exact rationals or as transcendental `Root[{f, x0}]` objects. `Reduce[Sin[x] > x/2, x, Reals]` gives `x < Root[{#1 - 2 Sin[#1] &, -1.89549}] || 0 < x < Root[{#1 - 2 Sin[#1] &, 1.89549}]`, as Mathematica does. Infinitely many roots (`Sin[x] > 0`) or no provable bound still leaves Reduce unevaluated. `Root[{f, x0}]` is certified by interval Newton, refines to any precision under `N`, canonicalises x0 and its body, and gives `Root::invrt` for an x0 that is not at a root. A six-digit printed x0 reads back.
- **Reduce input normalisation.** `Not[a > b]` folds to `a <= b`, with De Morgan through `And` and `Or`, and over Reals a relation side carrying `Re`/`Im`/`Conjugate` is ComplexExpanded. A residual that vanishes on a whole interval (`ArcCos[1 - 2 x^2] - 2 ArcSin[x]` on [0, 1]) is decided cell by cell instead of burning the isolation budget. This restores `Refine[Cos[x] > 0, -Pi/2 < x < Pi/2] = True`, `Simplify[ArcCos[1 - 2 x^2] - 2 ArcSin[x], 0 < x < 1/2] = 0` and `Simplify[Sqrt[E^(2 I x)] - E^(I x), -Pi/2 < x < Pi/2] = 0`. All three had regressed in v0.464, which had removed the unsound one-sample shortcut that had decided them by luck.
- **Rules on ordered Flat heads are cheap again.** A failing rule on `**`, `Dot`, `And`, `Or` or a user `Flat` head paid a full match at every start offset after v0.462: seconds at n = 100 for `ff[x_, y_, x_]`, and n³ for `And[x_, Not[x_]]`. Offsets and spans that cannot match are now skipped using the pattern's first single-operand element as an anchor, and a group that cannot equal an already-bound name is rejected without being built. Repeated-name and anchored rules now cost about what v0.461 did. `PatternSequence[...]` elements now also match interior runs.
- **FactorInteger: bignum Fermat and Lehman.** The Fermat residue filter tests 64 candidates per block with precomputed bit masks: 0.5 ns per value instead of 10 ns. The Lehman sweep gives k = 1 about 5/6 of each round, and a larger "Iterations" never finds less. Near-square factors are cheap again (NextPrime[10^25]·NextPrime[10^25+10^16] takes 2.5 ms, against 77 ms in v0.464), and ratio-3, 5/7 and 2/3 factors stay at a few ms. The default Lehman budget is now 2^28.
- **InputForm round-trips machine reals.** `InputForm`/`FullForm` and `ToString[_, InputForm]` print a machine real as the shortest decimal that reads back to the same double (6 digits before), with the machine mark `` ` `` on a 17-digit mantissa and `*^` exponents. A machine `*^` literal now parses with one correct rounding (`1.5*^-5` was one ulp off).

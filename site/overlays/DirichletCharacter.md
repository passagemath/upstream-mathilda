### Worked examples

```mathematica
In[1]:= Table[DirichletCharacter[4, 2, n], {n, 1, 8}]  (* the non-principal character mod 4 *)
```

```mathematica
In[1]:= Table[DirichletCharacter[5, j, PrimitiveRoot[5]], {j, 1, 4}]  (* for prime k, the value at the primitive root is Exp[2 Pi I (j - 1)/(k - 1)] *)
```

```mathematica
In[1]:= Table[DirichletCharacter[8, j, n], {j, 1, 4}, {n, 1, 8}]  (* for modulus 8 the sign component <-1> is the most significant digit, then <5> *)
```

```mathematica
In[1]:= Table[DirichletCharacter[7, 4, n], {n, 1, 7}] == Table[JacobiSymbol[n, 7], {n, 1, 7}]  (* the quadratic character mod 7 is the Legendre symbol *)
```

```mathematica
In[1]:= {DirichletCharacter[45, 8, 7], DirichletCharacter[9, 2, 7] DirichletCharacter[5, 4, 7]}  (* a composite modulus factors over its prime-power parts *)
```

```mathematica
In[1]:= DirichletCharacter[7, 3, 15] == DirichletCharacter[7, 3, 3] DirichletCharacter[7, 3, 5]  (* complete multiplicativity *)
```

```mathematica
In[1]:= DirichletCharacter[12, 3, Range[1, 12]]  (* a packed integer buffer: a real character returns 0 and +-1 *)
```

```mathematica
In[1]:= DirichletCharacter[10^12 + 39, 5, 3]  (* a large prime modulus through Pohlig-Hellman discrete logs *)
```

```mathematica
In[1]:= DirichletCharacter[5, 6, 2]  (* an index beyond EulerPhi[5] emits DirichletCharacter::invl and stays unevaluated *)
```

### Notes

- **Labelling.** Mathilda reproduces Mathematica's index `j = 1..EulerPhi[k]`, which is not the Conrey labelling used by LMFDB and arb. `k` is factored with primes ascending into cyclic components: one per odd `p^a`, generated by its smallest primitive root; one for 4, generated by 3; and two for `2^a` with `a ≥ 3`, `⟨-1⟩` then `⟨5⟩`. `j - 1` is read in mixed radix with the first component most significant, and `χ(g_c) = exp(2πi d_c/ord_c)`. `j = 1` is the principal character. For a prime `k`, `DirichletCharacter[k, j, PrimitiveRoot[k]] = Exp[2 Pi I (j-1)/(k-1)]`.
- Values are exact: 0, a unit (±1, ±I), or a unit times `E^(I Pi r)`.
- `DirichletCharacter::invl` (`j > EulerPhi[k]`), `::intp` and `::int` all route through the message funnel, so `Quiet` and `Check` work.
- Attributes: `Protected` only, as in Mathematica; the builtin threads over lists itself. An int64 packed `n` with a real character returns an int64 buffer. There is no `Compile[]` lowering, because the values are exact.
- See also: `DirichletL`, `PrimitiveRoot`, `JacobiSymbol`, `MultiplicativeOrder`.
